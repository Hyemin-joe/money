# 머니 – 친구처럼 물어봐 주는 채팅 가계부

## 켜는 법
1. `시작하기.command` 파일을 더블클릭
2. 브라우저가 자동으로 열려요 (안 열리면 주소창에 http://localhost:3000)
3. 끌 때는 까만 터미널 창에서 `Control + C` 또는 창 닫기

## 쓰는 법
- 채팅창에 "스타벅스 5800", "점심 김밥 4천원", "월급 300만원 들어옴" 처럼 입력
- 잘못 기록되면 말풍선 아래 **되돌리기**
- 오른쪽 위 **통계** → 주 / 월 / 년 합계
- 카메라 버튼 → 영수증·결제 캡처 사진 (API 키 필요)
- 밤 9시 알림: 첫 화면의 **알림 켜기** (머니가 켜져 있어야 알림이 와요)

## 사진 인식(AI) 켜기 – 구글 무료 키
1. https://aistudio.google.com/apikey 에서 구글 계정으로 로그인 → "API 키 만들기"
2. `.env` 파일의 `GEMINI_API_KEY=` 뒤에 키 붙여넣고 저장
3. 머니를 껐다 켜기 → 까만 창에 "켜짐 ✅ (구글 Gemini)"
- 무료 등급은 하루 사용 횟수 제한이 있고, 보낸 내용이 구글 서비스 개선에 쓰일 수 있어요.
- 유료 Claude 키를 쓰고 싶으면 `ANTHROPIC_API_KEY=` 에 넣으세요 (둘 다 있으면 구글을 먼저 씀).

## 파일 구조 (참고)
- `public/` 화면 (index.html, style.css, app.js)
- `server.js` 서버 / `lib/` 문장 해석·AI·통계·알림
- `data/db.json` 내 기록이 저장되는 곳 (백업하려면 이 파일을 복사)
